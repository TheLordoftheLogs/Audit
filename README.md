# Выездная проверка контрагента — Android-приложение

Электронная версия «Протокола выездной проверки контрагента» (Приложение 2) для заполнения на телефоне в полевых условиях.

## Что умеет
- Все разделы протокола: шапка, участники, разделы 1–5, таблицы техники, договоров, документов, субпоставщиков, рисков.
- Фото из любого раздела: на снимок впечатываются широта и долгота (6 знаков, ~10 см), точность GPS, дата, время с часовым поясом, номер протокола и раздел.
- Подписи участников и представителя контрагента пальцем на экране.
- Работает без интернета. Данные и фото автоматически сохраняются в памяти телефона — можно закрыть приложение и продолжить позже.
- Итог — PDF (A4): полный протокол + приложение с фотографиями. Сохраняется в «Загрузки/Проверки контрагентов», кнопка «Отправить» открывает почту/мессенджеры.

## Сборка APK

Вариант 1 — Android Studio (Koala или новее):
1. File → Open → выбрать папку проекта. Studio сама скачает Gradle и зависимости.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Вариант 2 — без Android Studio, через GitHub:
1. Загрузить папку в репозиторий GitHub (ветка `main`).
2. Вкладка Actions → «Сборка APK» → Run workflow.
3. Через ~5 минут скачать APK из раздела Artifacts.

Для распространения внутри компании (MDM, Google Play) соберите release-версию с подписью: Build → Generate Signed App Bundle / APK.

## Установка на телефон
Android 8.0 и новее. Скопируйте APK на телефон, откройте его и разрешите установку из этого источника. При первом запуске разрешите доступ к местоположению и камере.

## Изменение формы
Вся логика и форма находятся в одном файле `app/src/main/assets/index.html`.
Структура протокола описана в начале скрипта в массиве `SCHEMA` — пункты, таблицы и строки можно добавлять/править там, и форма, и PDF перестроятся автоматически.
Этот же файл можно открыть в Chrome на компьютере для проверки (GPS там берётся по Wi-Fi/IP).
